## 👋 Bem-vindo!

Este manual foi criado para ajudar você a usar o sistema Vibrant City Tours de forma simples e eficiente. Aqui você encontrará tudo o que precisa para:

- Consultar seus reviews

---

## 🔐 1. ACESSANDO O SISTEMA

### Primeiro Acesso
1. Você receberá um email com:
   - Link de acesso: `https://dashboard.vibrantcitytours.com`
   - Seu email de login
   - Senha temporária

2. **IMPORTANTE**: Altere sua senha no primeiro acesso
   - Clique no seu nome (canto superior direito)
   - **Configurações** → **Alterar Senha**
   - Use uma senha forte e segura

### Login Diário
1. Acesse: `https://dashboard.vibrantcitytours.com`
2. Email: `seu_email@vibrantcitytours.com`
3. Senha: (a que você criou)

## 📅 2. SUA AGENDA

### Visualizar Próximos Tours
Ao fazer login, você verá automaticamente:
- **Seus próximos tours**: Data, hora, local
- **Tours de hoje**: Destacados no topo
- **Tours desta semana**: Lista completa

### Informações de Cada Sessão
Cada card mostra:
- 📍 **Local de encontro**: Onde começar o tour
- ⏰ **Horário**: Início e duração
- 👥 **Participantes**: Quantas pessoas confirmadas
- 🌍 **Idioma**: Idioma principal do grupo
- 📝 **Observações**: Notas importantes

### Como Ver Detalhes
1. Clique no card do tour
2. Você verá:
   - Lista de participantes
   - Países de origem
   - Histórico deste tour
   - Suas reviews anteriores

## 💰 5. GORJETAS E PAGAMENTOS

### Registrar Gorjetas do Dia
1. Após o tour, clique em **+ Adicionar Transação**
2. Ou no card do tour → **Registrar Gorjetas**
3. Preencha:
   - **Valor**: Quantia recebida (em Euros)
   - **Descrição**: Ex: "Free Walking Tour - 12 pessoas"
4. Clique em **Salvar**

### Consultar Histórico
- Menu **Financeiro**
- Filtre por período (semana, mês)
- Veja total acumulado
- Exporte para seus registros

### Balanço Mensal
- No final do mês, o administrador fecha o balanço
- Você recebe notificação
- Pode consultar e exportar relatório

## 📝 8. ATUALIZANDO SEUS DADOS

### Editar Seu Perfil
1. Clique no seu nome (canto superior direito)
2. **Meu Perfil**
3. Você pode editar:
   - Telefone
   - Idiomas (se aprendeu novo idioma!)
   - Foto de perfil
4. **Salvar Alterações**

### Marcar Férias
**IMPORTANTE**: Avise com antecedência!
1. Contate o administrador
2. Informe período de férias
3. Admin marca seu status como "FÉRIAS"
4. Sistema não te alocará automaticamente

### Voltar de Férias
1. Contate admin quando retornar
2. Status volta para "ATIVO"
3. Você aparece na lista de alocações

## 🆘 9. PROBLEMAS COMUNS

### Esqueci Minha Senha
1. Na tela de login → **Esqueci Minha Senha**
2. Digite seu email
3. Você receberá link para redefinir
4. Crie nova senha

### Não Vejo Meus Tours
**Possíveis causas:**
- Filtro de data está incorreto (mude para "Próximos 30 dias")
- Você foi marcado como "FÉRIAS" (contate admin)
- Ainda não foi alocado para novos tours

### Erro ao Registrar Gorjeta
- Verifique se o valor está correto (sem símbolos, use ponto para decimais)
- Tente fazer logout e login novamente
- Se persistir, contate suporte

### Sistema Está Lento
- Atualize a página (F5)
- Limpe cache do navegador
- Use Chrome ou Firefox atualizados
